\section{Getting Started}
\label{sec:gettingstrated}

\CM~is the main component of this software package.
To make electromechanical simulations possible, the additional components \ACC~and \CMT~(with subcomponents \EMT~and \FMT) were added and can be utilized via the plugin interface of \CM.
Currently, no precompiled version is available and the entire software has to be build from source.
Make sure to follow the build instructions  (\href{https://github.com/KIT-IBT/CardioMechanics/blob/main/docs/BUILD.md}{docs/BUILD.md}) to install from source using CMake or read the following section.

\subsection{System Requirements}

The following requirements have to be installed before trying to build CardioMechanics from source.
We recommend using a package manager (e.g. \href{https://brew.sh}{Homebrew} on macOS or \verb|apt| on Ubuntu) whenever possible.
\begin{itemize}
    \item C and C++ compilers (e.g. gcc/g++ or clang/clang++)
    \item \href{https://cmake.org}{CMake} $\geq$ 3.20
    \item \href{https://www.freedesktop.org/wiki/Software/pkg-config/}{pkg-config}
    \item \href{https://zlib.net}{zlib}
    \item \href{https://gcc.gnu.org/fortran/}{gfortran}
    \item \href{https://git-scm.com}{git}
    \item \href{https://petsc.org/}{PETSc} (built with \verb|--prefix| so that a \verb|PETSc.pc| pkg-config file is generated)
    \item \href{https://vtk.org}{VTK} $\geq$ 9
    \item \href{https://www.open-mpi.org}{Open MPI}
    \item \href{https://www.python.org}{Python3} (optional, for the tools in \verb|tools/python/|)
\end{itemize}
The \verb|docker/| directory contains Dockerfiles that build \href{https://www.open-mpi.org}{Open MPI}, \href{https://petsc.org/}{PETSc}, and \href{https://vtk.org}{VTK} from source with tested versions and can serve as a reference for building the dependencies manually.

\subsection{Installation Instructions}

Only \verb|PETSC_DIR| (and optionally \verb|PETSC_ARCH|) are required so that CMake can locate the PETSc pkg-config file. Add them to your shell configuration file (e.g. .bashrc or .zshrc):
\begin{lstlisting}[language=bash]
export PETSC_DIR=/path/to/petsc   # prefix install directory
export PETSC_ARCH=                 # leave empty if PETSc was installed with --prefix
\end{lstlisting}
If \verb|PETSC_ARCH| is empty, the pkg-config file is expected at \verb|$PETSC_DIR/lib/pkgconfig/PETSc.pc|; if it is non-empty, at \verb|$PETSC_DIR/$PETSC_ARCH/lib/pkgconfig/PETSc.pc|.
VTK and Open MPI are found via CMake's standard search paths; on macOS with Homebrew no extra variables are needed.

Configure and build using the provided presets (binaries are placed in \verb|_build/<preset>/bin/|):
\begin{lstlisting}[language=bash]
cmake --preset release
cmake --build --preset release -j
\end{lstlisting}
Use the \verb|debug| preset in the same way for a debug build. To build without presets, run \verb|cmake -S . -B _build/release -DCMAKE_BUILD_TYPE=Release| followed by \verb|cmake --build _build/release -j|.

Finally, add the executables and Python tools to your PATH variable:
\begin{lstlisting}[language=bash]
export PATH="$PATH:/path/to/CardioMechanics/_build/release/bin"
export PATH="$PATH:/path/to/CardioMechanics/tools/python"
\end{lstlisting}
See \href{https://github.com/KIT-IBT/CardioMechanics/blob/main/docs/BUILD.md}{docs/BUILD.md} for pinning \verb|PETSC_DIR| per preset via a local \verb|CMakeUserPresets.json| and for troubleshooting.
